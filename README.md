# PlittGiocomo_CA1Morph_2019

Code for analysis and modeling in Plitt & Giocomo (2019): *Experience-dependent contextual codes in the hippocampus*.

> **Note on data updates**: This repository includes data not in the original publication. Place cells were re-calculated using an updated shuffling procedure. All results replicate with the additional data, though exact values change for certain analyses.

---

## Overview

This repository contains the analysis pipeline for two-photon calcium imaging of CA1 place cells in mice running a virtual reality morphing task. Mice were exposed to a VR environment whose visual features (wall grating frequency and angle) continuously morphed between two endpoints (S=0 and S=1). Neural representations were recorded and analyzed to study how prior experience shapes spatial coding in hippocampus.

Two morphing conditions are compared:
- **Rare morphing**: stimuli drawn from a bimodal distribution (mostly S=0 and S=1)
- **Frequent morphing**: stimuli drawn from a uniform distribution (S=0, 0.25, 0.5, 0.75, 1)

Key analyses include place cell detection, trial-by-trial similarity matrices, similarity fraction decoding, Bayesian MAP estimation under empirical priors, and non-negative matrix factorization (NMF) of single-cell activity.

## Setup

### Requirements

- Python 3.11.14 (pinned in `pyproject.toml`)
- [`uv`](https://github.com/astral-sh/uv) package manager (recommended)

### Installation

Use the provided `uv.lock` file to reproduce the exact environment used for the analyses:

```bash
uv sync
```

This installs all dependencies (including the pinned git-sourced packages `two_photon_utils` and `nmftools`) at the exact versions used in the paper. Do **not** use `pip install` directly — the lock file ensures reproducibility.

To activate the environment:

```bash
source .venv/bin/activate
```

## Getting the Data

### Two-photon and VR behavioral data

The calcium imaging (NWB) and VR behavioral data are hosted on DANDI. See the notebook [notebooks/01_DOWNLOAD_DATASETS.ipynb](notebooks/01_DOWNLOAD_DATASETS.ipynb) for step-by-step download instructions.

> **Warning**: The full dataset is approximately 110 GB. Ensure you have sufficient disk space before downloading.

The download notebook uses the DANDI API (`dandiset_id = "000054"`) and saves data to the path configured in [`src/morph_analyses/params.py`](src/morph_analyses/params.py). You may need to edit `params.py` to point `dandi_download_dir` to your preferred storage location.

### Loading a session

Sessions are stored as NWB files and loaded via the `CA1MorphSession` class:

```python
import morph_analyses as m

# Load a test session for mouse R1, day 8
sess = m.sess.CA1MorphSession.from_nwb('R1', 'testing', day=8)

# Access neural data (neurons x timepoints after Suite2P)
spks = sess.timeseries['spks_norm']   # normalized deconvolved activity

# Access behavioral data (pandas DataFrame, 2P-aligned)
vr_data = sess.vr_data

# Access pre-computed trial matrices (trials x position bins x neurons)
trial_mat = sess.trial_matrices['spks_norm']

# Access place cell results
masks = sess.place_cell_info   # dict keyed by morph value
```

## Key Concepts

**Morph value** (`morphs`): The mean visual stimulus presented on a trial, ranging from 0 (S=0, low frequency/angle) to 1 (S=1, high frequency/angle). Includes integer (0, 0.25, 0.5, 0.75, 1) and continuously varying intermediate values.

**Effective morph** (`effective_morph`): `morphs + wallJitter` — the actual stimulus seen by the animal on each trial, accounting for per-trial jitter added to the wall cues.

**Wall morph** (`wallmorphx`): The effective morph value rescaled to match the linear range of the horizontal wall grating frequency, used as the stimulus axis for Bayesian inference.

**Similarity fraction** (`sf`): For each trial, the cosine similarity to the average morph=1 representation divided by the sum of cosine similarities to the morph=0 and morph=1 averages. A value near 1 means the population pattern resembles S=1; near 0 resembles S=0.

**Spatial information** (SI, bits/spike): Skaggs & McNaughton metric quantifying how much a cell's firing rate conveys information about the animal's location. Used to identify place cells via permutation test.
